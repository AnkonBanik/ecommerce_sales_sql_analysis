# Ecommerce Sales SQL Analysis

## Overview
This project demonstrates a **complete end-to-end SQL workflow** on an ecommerce sales dataset. It covers **database schema design, data loading, validation, analysis, and business insights**. 


## Folder Structure
ecommerce-sales-sql-analysis/
├── data/ # Raw dataset / SQL dump
│ └── ecommerce_sales.sql
├── sql/ # SQL scripts following workflow steps
│ ├── 01_schema.sql
│ ├── 02_data_load.sql
│ ├── 03_data_validation.sql
│ ├── 04_basic_analysis.sql
│ ├── 05_advanced_analysis.sql
│ └── 06_business_insights.sql
├── results/ # Analysis results and insights
│ └── insights.md
├── README.md
└── LICENSE



## Project Workflow
1. **Schema Design:** Define tables, data types, constraints (`01_schema.sql`)  
2. **Data Loading:** Insert sample data into tables (`02_data_load.sql`)  
3. **Data Validation:** Ensure data quality and integrity (`03_data_validation.sql`)  
4. **Basic Analysis:** Perform summary statistics and simple queries (`04_basic_analysis.sql`)  
5. **Advanced Analysis:** Complex queries, joins, aggregations, trends (`05_advanced_analysis.sql`)  
6. **Business Insights:** Extract actionable insights for decision making (`06_business_insights.sql`)  



## Key Skills Demonstrated
- SQL DDL & DML
- Data validation & quality checks
- Analytical queries & reporting
- Business problem-solving
- Clear workflow documentation



## How to Run
1. Import the SQL scripts into your **MySQL/PostgreSQL** database.  
2. Execute scripts **in order** (01 → 06).  
3. Check results in `results/insights.md`.
